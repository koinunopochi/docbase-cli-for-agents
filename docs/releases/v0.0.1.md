# v0.0.1

Initial public release of DocBase CLI for AI agents.

Highlights:

- DocBase API v3 access through a small Python 3.12+ CLI.
- JSON output for agent-friendly parsing.
- Environment-only authentication with `DOCBASE_DOMAIN` and
  `DOCBASE_API_TOKEN`.
- Private-draft default for new posts and owner checks for post mutations.
- Detailed command, authentication, safety, and output documentation.
- `tar.gz`, ZIP, and SHA256SUMS assets generated by GitHub Actions.

Download an archive from the release assets, verify `SHA256SUMS`, extract it,
and run `bin/docbase`. No local build is required.
