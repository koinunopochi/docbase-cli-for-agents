# v0.1.2

This release makes the CLI contract self-describing and enforces its safety
boundary at runtime.

- All DocBase API mutations require `--confirm`.
- Invalid IDs, pagination, dates, and patch ranges are rejected before a
  request.
- Errors are structured JSON on stderr with exit code, retryability, status,
  and next action; API tokens are redacted.
- `--include-meta` exposes HTTP and rate-limit metadata without changing the
  default success JSON.
- Attachment downloads do not overwrite existing files unless
  `--overwrite --confirm` is supplied.
- Release archives include the complete versioned documentation tree.
