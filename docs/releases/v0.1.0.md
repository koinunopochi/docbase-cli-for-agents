# v0.1.0

Highlights:

- `upload-attachment`: upload a local file to DocBase as an attachment.
- `create-post`, `update-post`, and `patch-post-body` reject an ATX H1
  heading (`# ...`) in the body, since DocBase already renders the post
  title as an H1 and a body H1 duplicates it. Code fences (``` / ~~~) are
  excluded from the check; see [safety.md](../safety.md#body-content) for
  the exact rules and known limitations (Setext headings, indented code
  blocks, `patch-post-body`'s fragment-only scope).
- CI: release workflow now loads a tag-specific release-notes file when one
  exists, and uses the current checkout action.

Download an archive from the release assets, verify `SHA256SUMS`, extract it,
and run `bin/docbase`. No local build is required.
