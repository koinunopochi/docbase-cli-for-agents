# v0.1.1

Highlights:

- `create-post` always creates a private draft and no longer accepts publication-state flags.
- Post mutation commands no longer expose an owner-check override and always verify the authenticated user owns the post.
- Updated the command reference, safety documentation, and offline tests for the enforced safety boundary.

Download an archive from the release assets, verify `SHA256SUMS`, extract it,
and run `bin/docbase`. No local build is required.
