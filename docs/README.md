# Documentation

Use the CLI help as the short, versioned entry point:

```sh
./bin/docbase --help
./bin/docbase <command> --help
```

The help output links to the detailed [command reference](commands.md).

| Need | Read |
| --- | --- |
| Configure credentials | [Authentication](authentication.md) |
| Choose a command and arguments | [Command reference](commands.md) |
| Understand write safeguards | [Safety model](safety.md) |
| Consume JSON and handle errors | [Output and errors](output.md) |
| Download or publish a release | [Releases](releases.md) |

The API behavior is ultimately defined by DocBase. See the [official DocBase
API documentation](https://help.docbase.io/posts/45703) when an endpoint-level
detail is not covered here.
